# Security policy

Island can see the screen and, with your approval, use the mouse, keyboard, PowerShell and
files. Security problems matter a lot here, so thank you for reporting them privately.

## Reporting a vulnerability

Please **do not open a public issue**. Instead:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, the Island version and the Windows version.

Only the maintainers can see these reports. Please do not include real API keys, personal
files or screenshots of private information; a made-up example is enough.

## Especially interesting

- Ways to make Island act on the computer without the approval it should ask for.
- Web pages, files, documents or connector results whose text makes Island follow
  instructions (prompt injection).
- Ways to read or leak saved API keys, chats, memory or files.
- Problems in the installer, the update check, or the native helpers.

## Supported versions

Fixes are made for the latest release. Please check that the problem still happens on it.

## After you report

The maintainers will confirm the report, work on a fix, and credit you in the release notes
unless you prefer not to be named. This is a volunteer project, so please allow reasonable
time before talking about the problem publicly.
